# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability. Report it privately through the repository owner's GitHub contact channel, including:

- a clear description of the issue;
- affected version or commit;
- steps to reproduce; and
- potential impact, if known.

Reports will be acknowledged as soon as practical. Please allow time for investigation and remediation before public disclosure.

## Safe use

This tool only accepts absolute `http` and `https` URLs and requires an explicit output path. It refuses to overwrite an existing file. Review any URL before encoding or distributing its QR code.
